dsh-llm-gateway

本地多供应商 LLM 网关
连接中…

供应商

每个供应商独立监听一个端口，可直接接入任意 OpenAI 兼容客户端；也可用「网关」页的聚合端点一次接入全部。

接入方式

支持 OpenAI 与 Anthropic 两种协议（同一组地址、不同路径）。 手机 / 平板 / 酒馆请用「局域网接入」里的地址（IP 实时探测，网络变化后自动更新），本机客户端用 127.0.0.1。 地址与令牌均可点击复制。
